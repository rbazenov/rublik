# Рублик 🪙 — школа финансовой грамотности для детей

Онлайн-курс финансовой грамотности для детей 8–17 лет (со 2 по 11 класс).
Российские реалии: рубли, детские карты, кэшбэк, «Авито», первые вклады.

## Что внутри

- **index.html** — самодостаточный сайт (≈76 КБ, ноль зависимостей, работает офлайн):
  - программа 4 уровней со 2 по 11 класс;
  - интерактивный демо-урок «Бюджет: собери 4 000 ₽» — теория, игра-симулятор, квиз, диплом;
  - мини-игра «Хочу или нужно?» для 8–10 лет.
- **app/index.html** — личный кабинет ученика (прототип):
  - прогресс по 24 модулям, XP, ранги и серия дней;
  - копилка с правилом трёх банок и дневником денег;
  - недельные офлайн-миссии и достижения;
  - раздел для родителей с настройками;
  - прогресс демо-урока и мини-игры с лендинга засчитывается автоматически (localStorage);
  - быстрый просмотр с данными: `/app/?demo=1`.
- **DEPLOY.md** — пошаговая инструкция развёртывания на своём сервере (nginx, Caddy, Docker).

## Запуск локально

Просто откройте `index.html` в браузере.

Или мини-сервер: `python3 -m http.server 8000` → http://localhost:8000

## Онлайн-версия

Сайт публикуется через **GitHub Pages**: Settings → Pages → ветка `main`, корень репозитория.
